# A Homer Commentary in Progress

The Greek TEI JSON used for rendering the base text was generated by `mix kodon.parse`
(see [kodon_ex](https://github.com/pletcher/kodon_ex)).

## Development

Run `mix setup` to install dependencies and build assets, then start the development
server with `mix phx.server`.

## Deployment

Deployment is handled by a GitHub workflow. It builds a static version of the site
using `mix generate_static`. You can verify the output of this command by running
`mix generate_static` and then `mix serve_static` locally before you deploy.
